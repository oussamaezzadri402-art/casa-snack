========================================================================
       CASA SNACK - STATICAL RE-STRUCTURED WEB PROJECT
========================================================================

هذا المشروع يمثل الهيكلة الاحترافية والمنظمة لصفحة الهبوط الخاصة بمطعم وجبات السريعة Casa Snack.
تم نقل الأكواد بالكامل من البنية المعقدة إلى بنية ملفات ويب قياسية وثابتة (Static Plain Web Architecture) لضمان أقصى أداء وسرعة تحميل، مع سهولة التطوير والتعديل المستقبلي.

محتويات بنية المشروع:
====================
Casa Snack/
│
├── index.html     : الملف الأساسي لصفحة الهبوط (يحتوي على كامل هيكل الـ HTML5، شاشات التحميل، والـ Modals).
├── style.css      : ملف التنسيقات الخارجي (يحتوي على استيراد Tailwind CSS والحركات المخصصة).
├── script.js      : محرك التفاعلية المركزي (يحتوي على كائن بيانات المطعم restaurantConfig وجميع أحداث البرمجة التفاعلية).
│
├── assets/        : مجلد الوسائط والصور:
│   ├── images/    : يحتوي على صور الخلفية والمطبخ (hero.jpg, about_kitchen.jpg).
│   ├── logo/      : يحتوي على شعار المطعم الرسمي (logo.jpg).
│   └── icons/     : يحتوي على الأيقونات وملحقات التصميم الإضافية.
│
└── README.txt     : هذا الملف (دليل التشغيل والتعليمات).


طريقة إدارة وتعديل معلومات المطعم (restaurantConfig):
==================================================
لقد قمنا بجمع وتوحيد جميع بيانات وتفاصيل المطعم داخل كائن جافاسكريبت واحد مركزي باسم `restaurantConfig` في بداية ملف `script.js`.
يمكنك تعديل أي معلومة من معلومات المطعم بسهولة فائقة دون ملامسة كود الهيكل أو التنسيق:

1. الاسم والشعار: لتغيير الاسم أو مسار الشعار، عدل قيم الحقول:
   - name: "Casa Snack"
   - logo: "/assets/logo/logo.jpg"

2. أوقات العمل وحساب الحالة التلقائية:
   يمكنك تعديل قيم أوقات العمل بنظام 24 ساعة، وسيقوم المحرك المركزي في script.js بحساب وعرض حالة المطعم (مفتوح الآن 🟢 / مغلق حالياً 🔴) والوقت المتبقي بدقة تلقائياً:
   - openingHour: 11 (الحادية عشر صباحاً)
   - openingMinute: 30
   - closingHour: 2 (الثانية بعد منتصف الليل)
   - closingMinute: 0

3. التوصيل والاتصال:
   - phone: رقم الهاتف للطلبات المباشرة.
   - whatsappPhone: رقم الواتساب الذي ستتوجه إليه الطلبات بشكل منسق واحترافي.

4. قائمة الوجبات والأسعار (menuItems):
   يمكنك إضافة، تعديل، أو حذف أي وجبة من قائمة الوجبات مباشرة من مصفوفة `menuItems` وسيقوم الموقع بتحديثها في المنيو مع الفلترة والبحث الفوري وتوفير أزرار سلة التسوق تلقائياً!


ملاحظات التشغيل:
===============
1. الموقع متجاوب بالكامل 100% مع جميع الهواتف الذكية والأجهزة اللوحية والحواسيب المكتبية.
2. تفعيل حركات Smooth Scroll-Reveal الاحترافية التي تظهر العناصر بسلاسة عند النزول في الصفحة باستخدام IntersectionObserver.
3. نظام سلة مشتريات حقيقي يحفظ المشتريات محلياً ويسمح للزبون باختيار الصلصات المرافقة ثم إرسال الطلب النهائي منسقاً بالكامل لمالك المطعم على واتساب بنقرة واحدة.
4. توافق تام مع استضافات Netlify, Vercel, أو أي استضافة ثابتة بمجرد رفع المجلد.
